# Quentin — Portfolio (Vite + React)

Modern, animated portfolio website built with **Vite + React + TypeScript + Tailwind + Framer Motion**.
Designed to showcase **DevSecOps / Backend / AI Systems** work with a premium UI, smooth navigation, and live-ready pages.

## ✨ Features
- Premium animated hero + smooth section transitions
- Full-screen **Menu Overlay** (Home / Work / About / Contact / Stack)
- **Work** page with preview + modal details for projects
- **Stack** page (tools & technologies with logos)
- Light/Dark theme toggle
- FR / EN language toggle
- Metaballs shader background (React Three Fiber)
- Responsive layout (mobile → desktop)

## 🧱 Tech Stack
- **Vite** + **React** + **TypeScript**
- **Tailwind CSS**
- **Framer Motion**
- **react-router-dom**
- **three.js / @react-three/fiber / @react-three/drei**
